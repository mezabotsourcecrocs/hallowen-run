📖 Tutorial

🎮 Kontrol Desktop

⎵Tekan Space atau ↑ Arrow untuk lompat
🖱️Klik di area game juga bisa untuk lompat
🦘Double jump — tekan lagi saat masih di udara!
⚠️ Pastikan jendela browser tidak dalam mode zoom terlalu kecil/besar agar tampilan game tetap pas.
💡 Kalau laptop/PC kamu spesifikasinya rendah dan game terasa berat/patah-patah, ubah grafis ke Super Low di menu Options ⚙️ supaya lebih ringan.

🎮 Kontrol Handphone

👆Tap layar untuk lompat
🦘Double jump — tap lagi saat masih di udara!
📱 Putar HP ke mode landscape (mendatar) supaya game bisa tampil dan berfungsi sepenuhnya!
🚫 Jangan aktifkan mode "Tampilan Desktop" di browser HP kamu (Chrome/Safari, dll) — ini bisa membuat game tidak berfungsi dengan baik.
💡 Kalau HP kamu low-end / spek rendah dan game terasa berat/patah-patah, ubah grafis ke Super Low di menu Options ⚙️ supaya lebih ringan.

📖 Cara Bermain

🎮 Kontrol

⎵Tekan Space atau ↑ Arrow untuk lompat (keyboard)
👆Tap / klik layar untuk lompat (HP & mouse)
🦘Double jump — lompat sekali lagi saat masih di udara!

🎯 Tujuan

🏃Lari sejauh mungkin, hindari rintangan & kumpulkan permen 🍬 untuk menambah skor
⚡Makin lama bermain, game makin cepat dan rintangan makin rapat!

🚧 Rintangan

🎃💀🕷️Tanah — lompat!
🌵🦴🪦Tanah — lompat!
🦇👻Terbang — single jump
🕸️🦅Terbang — double jump

❤️ Nyawa & Combo

❤️Kamu punya 3 nyawa. Kena rintangan = -1 nyawa. Habis = Game Over
🎁Bonus nyawa otomatis tiap 1000 poin (maks 3)
🔥Kumpul permen beruntun tanpa kena → Combo x2 → x3 → x4 FEVER!

⚡ Power-Up

🛡️Perisai — kebal 1x tabrakan tanpa kehilangan nyawa
⏰Slow-Mo — game melambat sementara, lebih mudah menghindar
🧲Magnet — permen di sekitar otomatis tertarik ke kamu
💰2x Skor — semua skor yang didapat dikali 2 sementara
🚀Super Jump — lompatan jauh lebih tinggi
👡 Sandal Crocs (SPECIAL) — 3 sandal berputar mengelilingi kamu dan menghancurkan rintangan otomatis! Berkurang 1 tiap rintangan hancur
